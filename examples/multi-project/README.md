# Multi-project documentation example

These content folders demonstrate separate Platform and CLI documentation spaces. They are intentionally outside the Indocio documentation app, so that app has no product selector or sample product routes.

To try the example, copy `content/products/` into your consuming app’s `content/products/` directory. Nuxt Content discovers the folders, their page order, and their `.navigation.yml` metadata. The product selector appears automatically when both spaces are present.

See the Multiple products guide in the documentation for configuration and a screenshot. The localized integration fixture also exercises multi-project navigation.
