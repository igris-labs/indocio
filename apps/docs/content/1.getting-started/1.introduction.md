## Welcome to Indocio

Write your documentation in Markdown. Indocio provides the navigation, page layout, table of contents, search, and theme controls around your content.

## Built on IPEX

The interface uses IPEX's design tokens and components, with Akaza UI providing the headless primitives. UI components are available with the `Ui` prefix, such as `UiButton` and `UiTabs`.

::note{title="A starting point"}
This project is the foundation. Add your documentation to the `content/` folder and configure the home page in `content/index.yml`.
::

## Write in Markdown

Nuxt Content renders headings, lists, tables, and code blocks. Indocio includes IPEX's prose styles and callouts for Markdown usage.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@igrislabs/indocio'],
})
```
