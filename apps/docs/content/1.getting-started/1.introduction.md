## Welcome to Indocio

Write your documentation in Markdown. Indocio provides the navigation, page layout, table of contents, search, and theme controls around your content.

## Built on IPEX

Use IPEX components for the interface, with Akaza UI for keyboard controls and accessibility. Add UI components with the `Ui` prefix, such as `UiButton` and `UiTabs`.

::note{title="A starting point"}
Add your documentation to `content/`. Set the home page title, description, and links in `content/index.yml`.
::

## Write in Markdown

Write headings, lists, tables, and code blocks with Markdown. Add callouts to highlight notes, tips, or warnings.

## Install Indocio

Use Node.js 22.19 or newer with a Nuxt 4 app. Install the package in your app:

```sh
pnpm add @igrislabs/indocio
```

Add the layer to `extends` in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@igrislabs/indocio'],
})
```

Remove the starter `app/app.vue` to use Indocio's app layout. Add your first Markdown page to `content/` and configure the home page in `content/index.yml`.

Start the development server with `pnpm dev`.
