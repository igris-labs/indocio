## Choose a configuration file

Use `nuxt.config.ts` for modules, i18n, and build settings. Use `app/app.config.ts` for the documentation interface. Keep brand colors and typography in your app's CSS. Keep page settings in Markdown frontmatter and section settings in `.navigation.yml`.

Choose the settings you want to change. Nuxt provides autocomplete for `@igrislabs/indocio` through the layer's app configuration.

```ts [app/app.config.ts]
export default defineAppConfig({
  indocio: {
    docs: {
      content: { width: '42rem' },
      sidebar: { enabled: true, width: 240, collapsible: false },
      toc: { enabled: true, position: 'content', depth: 3 },
      breadcrumbs: true,
      footer: true,
      navigation: true,
      search: true,
      actions: { copyLink: true },
    },
    spaces: { switcher: 'dropdown' },
  },
})
```

The example shows the defaults. `navigation` controls previous/next links. `sidebar.width` is a number in pixels, between 180 and 480. Enable `sidebar.collapsible` to show a desktop toggle; the mobile drawer remains available whenever the sidebar is enabled.

## Keep the article centered

`content.width` sets the article's maximum width. Use a positive CSS length such as `42rem`, `800px`, or `75ch`. Keep the article centered on the screen while you adjust the sidebar and table of contents. On smaller screens, readers see a narrower article.

```ts [app/app.config.ts]
export default defineAppConfig({
  indocio: {
    docs: {
      content: { width: '48rem' },
      toc: { position: 'right' },
    },
  },
})
```

Choose `content` to keep the table of contents (TOC) beside the article, or `right` to place it at the layout's right edge. Keep the article centered with either option. On smaller screens, readers can expand the TOC above the page content.

Set `toc.depth` from 2 to 6 to choose the deepest heading level to show. Set the matching Markdown parsing depth in `nuxt.config.ts`. For example, to include heading levels 2–4:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@igrislabs/indocio'],
  content: {
    build: { markdown: { toc: { depth: 2, searchDepth: 4 } } },
  },
})
```

## Page and product overrides

Use the [live customizer](/getting-started/customizer) to preview changes over your saved configuration. Choose **Reset** to return to the settings in your files.

Choose settings for a page in its frontmatter, for a product in `.navigation.yml`, or for the site in `app.config.ts`. Page settings take priority over product settings, which take priority over site settings and defaults. Change `toc.position` without replacing `toc.enabled` or `toc.depth`.

```yaml [content/api/reference.md]
---
title: API reference
docs:
  content:
    width: 60rem
  toc:
    position: right
  actions:
    copyLink: false
---
```

Use the same `docs` object in a product's `.navigation.yml`. If you enter an invalid setting or misspell a field, check the error for the file and field to fix.

## Edit links

Configure an edit URL with a `{path}` placeholder. Use it to link to the Markdown file under `content/`, including numbered folders, language folders, and the `.md` extension. Indocio encodes spaces and special characters in the URL.

```ts [app/app.config.ts]
export default defineAppConfig({
  indocio: {
    docs: {
      actions: {
        edit: {
          url: 'https://github.com/your-org/docs/edit/main/content/{path}',
          label: 'Improve this page',
        },
      },
    },
  },
})
```

Set `actions.edit: false` on a page or space to disable an inherited edit link.

Use the repository's actual content location in the URL, for example `apps/docs/content/{path}` in a workspace.

## Layout CSS variables

Override these variables on `.docs-layout` in your application's stylesheet:

| Variable               | Default  | Purpose                                  |
| ---------------------- | -------- | ---------------------------------------- |
| `--docs-header-height` | `3.5rem` | Header height and sticky offsets         |
| `--docs-toc-width`     | `13rem`  | Desktop TOC width                        |
| `--docs-toc-gap`       | `6rem`   | Gap beside the article in `content` mode |

Set sidebar and article widths in `app.config.ts` to keep their sizes in sync. The sidebar divider continues through the header.

## Header links

Both landing and documentation headers read `indocio.header.links`. Groups use IPEX's sliding navigation. Use internal links without a language prefix here; readers follow them in their selected language.

```ts [app/app.config.ts]
export default defineAppConfig({
  indocio: {
    header: {
      links: [
        { label: 'Guides', to: '/getting-started/introduction' },
        {
          label: 'Writing',
          children: [
            {
              label: 'Markdown tabs',
              to: '/components/tabs',
              icon: 'tabler:components',
              description: 'Write richer Markdown.',
            },
          ],
        },
      ],
    },
  },
})
```

Keep your header links in your app's configuration. See [Component overrides](/getting-started/overrides) for custom header actions and other extension points.
